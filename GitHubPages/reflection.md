# Reflection: GitHub Pages (STAR Technique)

## S – Situation
The final requirement of my Digital Portfolio assignment for Project Presentation 3 (PRP370S) was to **publish my portfolio using GitHub Pages**. GitHub Pages is a free static site hosting service provided by GitHub that takes Markdown or HTML files directly from a repository and publishes them as a website. This step was essential to make my portfolio publicly accessible via a professional URL, rather than only viewable through the raw GitHub repository.

## T – Task
My task was to deploy my completed GitHub portfolio — including my Markdown-coded CV, STAR reflections, and embedded mock interview video — as a live website using GitHub Pages. The published site needed to be accessible, well-structured, and navigable, serving as a professional digital presence that I could share with potential employers and submit as my assignment deliverable via Blackboard.

## A – Action
I began by navigating to my repository's **Settings** tab on GitHub and locating the **Pages** section. I configured GitHub Pages to deploy from the `main` branch, using the root (`/`) directory as the source. After saving the settings, GitHub automatically built and deployed my site. I then verified that the site was live by visiting the generated URL (`https://milanincana.github.io/My-Digital-Portfolio/`). I tested all internal links to ensure navigation between the README, CV, and reflection pages worked correctly. I also verified that the embedded mock interview video rendered properly on the published site. Where links were broken, I corrected the relative paths in my Markdown files and pushed the fixes to trigger a redeployment.

## R – Result
My portfolio was successfully published on GitHub Pages and is now publicly accessible as a live website. Through this process, I gained the following skills and insights:

- Configuring and deploying a static site using GitHub Pages
- Understanding how GitHub Pages converts Markdown files into web pages
- Troubleshooting broken links and relative paths in a deployed environment
- Recognising the difference between how content renders on GitHub vs. GitHub Pages
- Creating a professional, shareable URL for my digital portfolio

Publishing on GitHub Pages transformed my repository from a collection of files into a professional online portfolio. This is a valuable skill for any software developer, as many open-source projects, documentation sites, and personal portfolios are hosted on GitHub Pages. I now have a live, shareable portfolio that demonstrates both my technical skills and my ability to present work professionally.
