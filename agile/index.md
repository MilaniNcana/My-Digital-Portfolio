# Agile Project Evidence — QAMS

**Project:** QR Code Attendance Management System (QAMS)

**Tagline:** *Attendance, verified.*

**My role:** Product Owner and Agile Lead / Scrum Master

**Module:** Project Presentation 3 (PRP370S / PRP371S / PRP372S) — CPUT, Faculty of Informatics and Design

QAMS replaces paper attendance registers with time-limited, rotating QR codes. A lecturer starts a class session and the system shows a QR code that refreshes on screen. Students scan it to check in, and the system records attendance, blocks duplicate check-ins and flags late arrivals.

This section of my portfolio contains the Agile artefacts our team produced while planning QAMS. Each artefact page has the evidence first, followed by my reflection using the STAR method (Situation, Task, Action, Result).

## Connecting the artefacts

The artefacts build on each other. The **Team Charter** set how we would work. The **User Stories** turned the business case into features users care about. Those stories became the **Product Backlog**, which we pulled from into each **Sprint Backlog**. The **Logbook** records what actually happened each week, including the blockers that changed our plans.
