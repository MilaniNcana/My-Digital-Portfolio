# Agile Project Evidence — QAMS

**Project:** QR Code Attendance Management System (QAMS)
**Tagline:** *Attendance, verified.*
**My role:** Product Owner and Agile Lead / Scrum Master
**Module:** Project Presentation 3 (PRP370S / PRP371S / PRP372S) — CPUT, Faculty of Informatics and Design

QAMS replaces paper attendance registers with time-limited, rotating QR codes. A lecturer starts a class session and the system shows a QR code that changes every 30 seconds. Students scan it with their phone to check in, and the system records attendance, blocks duplicate check-ins and marks late arrivals.

The project ran in two phases. From July to early August we planned the system in four one-week sprints on Trello. From late August to October I built, tested and deployed the working system: a Vue.js 3 frontend on Vercel, a Spring Boot API on Render and a MySQL database on Aiven.

This section of my portfolio contains the Agile artefacts from both phases. Each artefact page has the evidence first, followed by my reflection using the STAR method (Situation, Task, Action, Result).
